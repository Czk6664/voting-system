========================================
  快速部署步骤
========================================

方式一：Linux/Mac 一键部署
--------------------------
1. 上传代码到服务器
   scp -r ./* user@your-server:/path/to/app/

2. 登录服务器
   ssh user@your-server
   cd /path/to/app/

3. 运行部署脚本
   chmod +x deploy.sh
   ./deploy.sh

方式二：Windows 一键部署
--------------------------
1. 双击运行 deploy.bat

方式三：Docker 部署
--------------------------
1. 上传代码到服务器
2. 运行：docker-compose up -d

========================================
  重要提醒
========================================

⚠️  部署前必做：
1. 复制 .env.example 为 .env
2. 修改 .env 中的管理员密码
3. 确保服务器已安装 Node.js 14+

🔒 安全建议：
1. 使用强密码（至少12位）
2. 启用 HTTPS（使用 Let's Encrypt）
3. 配置防火墙
4. 定期备份数据

========================================
  常用命令
========================================

PM2：
  npm run pm2:start    - 启动应用
  npm run pm2:stop     - 停止应用
  npm run pm2:restart  - 重启应用
  npm run pm2:logs     - 查看日志
  npm run pm2:status   - 查看状态

Docker：
  npm run docker:up    - 启动容器
  npm run docker:down  - 停止容器
  npm run docker:logs  - 查看日志
