========================================
  重要提示
========================================

⚠️ Cloudflare Pages 不支持 Node.js 应用！

本项目是 Node.js + Express 应用，无法直接部署到 Cloudflare Pages。

Cloudflare Pages 只支持静态网站（HTML/CSS/JS）。

========================================
  快速开始
========================================

方法 1: 使用 Vercel（推荐）
--------------------------
1. 双击运行: deploy-vercel.bat
2. 按提示登录 Vercel
3. 等待部署完成
4. 访问显示的网址

方法 2: 手动部署
--------------------------
npm install -g vercel
vercel login
vercel
vercel --prod

========================================
  Cloudflare 说明
========================================

如果你想使用 Cloudflare，有两个选择：

1. Cloudflare Pages (❌ 不可行)
   - 只支持静态网站
   - 不支持 Node.js
   - 无法部署本项目

2. Cloudflare Workers (⚠️ 需要改造)
   - 需要重写 80% 代码
   - 预计 2-3 天工作量
   - 不推荐

详细说明请查看: CLOUDFLARE_DEPLOY.md
